# website-builder-journal

Read [`SKILL.md`](SKILL.md) before modifying `The-Interdependency/The-Interdependency.github.io`.

Every website change transaction appends a By the builder record with date, time, model provenance per `website-builder-journal/SKILL.md`, and model-chosen prose, then passes the website's builder-history gate. Read-only inspection does not trigger it.

Before composing the entry, use the independent work phase and initial three-entry
research allowance in `SKILL.md`. Keep the subject and length free; preserve unknown
usage as `hmmm` when the host supplies no meter. The builder-history gate validates
the record, while the executor owns any token enforcement.
